# Legacy TUI (retired)

This is the v1 TUI. It has been **retired** in favor of
[`cockatiel_tui_v2-rs`](../cockatiel_tui_v2-rs) — the Blender-inspired BSP
layout TUI.

Do not run or extend this. The v2 TUI is the standard; it is a submodule at the
repository root and speaks the same engine protocol (`cockatiel-tui`).

History is preserved here (tracked inline in the parent repo) for reference.
